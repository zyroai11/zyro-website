    Trade: an agent in your terminal

    Tell it what to buy and the limits it must respect. It scans first, checks your rules, and only then places the trade.

    • Minimum scoreSkip any token that scores below the number you set.
    • Size limitsA maximum per trade and a maximum loss per day.
    • Stop lossSet on every position the moment it opens.
    • Runs on your machineYour keys stay with you.

    Live now. Install it with npm install -g zyro-agent, then run zyro init.

    zyro-agent
    $ zyro trade 0x7a3f…c21e --max 0.2eth
scanning token…
score 90, low risk ✓
rule: liquidity above $50K ✓
bought with 0.2 ETH ✓
stop loss set at -15% ✓
$
