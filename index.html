    Install it

    Install the agent in a minute

    It runs on your own computer, so your keys never leave it. Everything is simulated until you add --live and type yes.

    1. Install

      Needs Node 18+ and Python 3.10+. Works on macOS, Linux and Windows with WSL.

      $ npm install -g zyro-agent

    2. Create your settings

      Makes ~/.zyro/.env for your keys and rules.

      $ zyro init

    3. Scan, then try a buy

      The first buy runs in simulation, so nothing is spent.

      $ zyro scan 0x39dbed3a2bd333467115de45665cc57f813c4571

    Eight things Zyro reads on every scan

    Each check can lower the score. The report lists every one that did, so you see the reason and not only the number.

    Liquidity

    How much money sits in the pool. Thin pools move violently and are easy to drain.

    Buys and sells

    Plenty of buys with zero sells is the classic sign of a honeypot, a token you cannot sell.

    Pair age

    Pairs younger than 24 hours get a warning. Most rug pulls happen early.

    FDV against liquidity

    A valuation far above the pool means the price is not backed by much.

    Volume

    Volume many times larger than liquidity often points to wash trading.

    Holders

    The holder count from the chain explorer. A handful of wallets is a concentration risk.

    Contract

    Whether the source code is verified on Blockscout, so anyone can read what it does.

    Website and socials

    Whether the project lists any public presence at all.

    Where does the data come from?

    Market data for scans comes from DexScreener. The $ZYRO chart is read straight from the Pons curve contract on Robinhood Chain. Holder counts and contract verification come from Blockscout, the Robinhood Chain explorer. Balances are read from the chain itself.

    Does the bot ever ask for my keys?

    Never. Linking a wallet only needs your public address. Anyone asking for a seed phrase or private key in Zyro's name is a scammer.
